Destaques

Lidos dos indicadores da camada gold, com os limiares escritos no código da API para poderem ser discutidos.

Em que fases eles param

Quantos jogadores chegaram a cada fase e quantos conseguiram concluí-la. A parte laranja é quem chegou e ficou pelo caminho.

Atividade da turma

Tentativas por dia, separadas pelo resultado.

Quanto custa cada fase

Mediana de tentativas até vencer entre quem concluiu a fase (RN-012).

A turma aprende tentando?

Em que fração das vezes a enésima tentativa termina em vitória. Se a linha sobe, as derrotas estão ensinando algo.

Venceram aplicando o conceito?

Cada conceito tem um bloco que o representa. Este gráfico mostra quantos venceram usando esse bloco e quantos contornaram — por exemplo, vencendo a fase de repetição empilhando o mesmo ataque várias vezes. Vale também para as fases de reforço, que é onde mais interessa saber se o conceito pegou. Conceito que não se resume a um bloco, como combinação, fica de fora.

Jogador por fase

Tentativas que cada jogador precisou até vencer cada fase. Célula vazia significa que o jogador ainda não chegou lá.
